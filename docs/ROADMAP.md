# Roadmap (ideas only)

Short backlog of **ideas**. Not commitments, not implementation plans, not UI specs. If you build one, delete it here and capture durable rules in `DECISIONS.md` / `SYSTEM.md`.

## Product ideas

- Recurring / fixed slots (“turno fijo”) with owner approval
- Real WhatsApp (or richer email) confirmations & reminders
- Live subscription billing / plan enforcement (today schema ≠ product)
- Plan Pro: more employees, multi-business, extras
- More industries beyond beauty (e.g. consultorios / salud) with capability flags
- Custom domain per business
- Deeper client history / blocklist / promos
- Configurable slot granularity UX beyond current settings

## Engineering ideas

- Move industry definitions from code map → DB when the category set grows
